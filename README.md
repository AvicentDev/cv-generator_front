# CV Generator AI

Genera tu CV profesional con inteligencia artificial.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Build

```bash
npm run build
npm start
```

## Características

- Chat interactivo para recopilar información del CV
- Preview en tiempo real del CV
- Descargar CV en PDF
- Interfaz moderna y responsiva
